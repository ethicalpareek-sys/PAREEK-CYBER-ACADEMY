## ⚡ What Is PAREEK CYBER ACADEMY?

> **PAREEK CYBER ACADEMY** is a complete, browser-native cybersecurity learning environment — a single self-contained `index.html` file that runs entirely on static hosting. No backend. No database. No build step. No tracking. Everything — 3D cyber background, 33-level roadmap, interactive labs, terminal simulator, and the original CTF engine — runs inside the learner's browser.

### ▸ Who It Is For

| Audience | What You Get |
|---|---|
| **Beginners** | A path from "what is a CPU" to cloud security architecture |
| **Self-taught** | Ordered curriculum with prerequisites — no scattered tutorials |
| **Students** | Portfolio-ready platform to demonstrate real skills |
| **Professionals** | Deep dives into SOC, DFIR, cloud, DevSecOps, AI security |
| **Educators** | Ready-to-fork teaching environment for workshops |
| **CTF newcomers** | 100+ original safe simulated challenges with hints |

### ▸ Why It Exists

Most cybersecurity learning is scattered and disconnected from practice. This platform gives learners a **single ordered path** — every topic has prerequisites, every level has labs, every concept has a defensive counterpoint. Theory without practice decays. Practice without theory is fragile. Both are enforced here.
